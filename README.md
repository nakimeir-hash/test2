# Dashboard Flask App

This is a simple analytics dashboard web-app built using Flask. It displays example statistics for **Users**, **Revenue**, and **Active Sessions** in a visually appealing layout.

## Features

- Attractive dashboard UI (HTML + CSS inlined in Python)
- Example data shown in real-time
- Ready to replace with your real analytics/data sources
- Responsive design for desktop and mobile

## Getting Started

### 1. Install dependencies

Make sure you have Python 3.x installed.

Install Flask:
```bash
pip install flask
```

### 2. Run the app

```bash
python main.py
```
The server will start on http://127.0.0.1:5000/

### 3. Open the dashboard

Visit [http://127.0.0.1:5000/](http://127.0.0.1:5000/) in your browser.

## Customization

- Edit `main.py` to change the example stats (or connect to your real data source).
- Modify the HTML template in `dashboard_template` for layout or style changes.
